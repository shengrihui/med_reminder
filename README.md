# MedReminder - 用药提醒

一款简洁的 Android 用药提醒应用，帮助您按时服药。

## 功能特点

- 添加药品信息（名称、剂量、服用时间）
- 定时提醒服药
- 简洁直观的卡片式界面
- 支持开机自启动（重启后自动恢复提醒）

## 安装说明

### 下载 APK

前往 [Releases](https://github.com/shengrihui/med_reminder/releases) 页面下载最新版本的 APK 文件，直接安装即可。

### 最低要求

- Android 8.0 (API 26) 或更高版本

## 技术栈

- Kotlin
- Android SDK
- Material Design 3
- ViewBinding
- AlarmManager（系统闹钟）
- Notification（通知提醒）
