# MedReminder - 用药提醒

一款简洁的 Android 用药提醒应用，帮助您按时服药。

## 功能特点

### 药品管理
- 添加 / 编辑 / 删除药品，支持一天多次服药、自定义“早餐后”等服药名称，每次可设置多个提醒时间点
- 可配置日期间隔（每天 / 每 N 天）、时间间隔（不重复 / 每 N 分钟重复提醒）
- 支持跨天排期，按设置的天数间隔自动计算提醒日期

### 首页提醒
- 显示每个药品未来 3 次提醒时间，日期标签支持"今天""明天""后天"
- 当天未确认的服药任务即使超时仍保留在首页
- 一键标记“已服用”或“跳过本次”；确认后该次服药的剩余提醒全部停止

### 通知提醒
- 基于系统 `AlarmManager` 的精确闹钟，支持 Doze 模式下准时唤醒
- 通知栏显示“已服用”“稍后提醒”快捷操作，稍后时长可选10分钟、30分钟、1小时或自定义
- 重复提醒：可在设置中配置重复间隔，到点未操作自动再次提醒

### 历史记录
- 按药品分组展示，每组内按操作时间倒序排列
- 记录实际操作时间（精确到秒），支持单条删除和按药品清空
- 状态区分：已吃（绿色）、已忽略（黄色）

### 权限与可靠性
- 自动引导用户授权通知权限、精确闹钟权限、电池优化白名单
- 设备重启后自动恢复所有提醒闹钟，并补发当天关机期间错过的提醒
- 旧日期提醒不会跨天循环；未确认任务自动进入“已错过”历史

## 安装说明

### 下载 APK

前往 [Releases](https://github.com/shengrihui/med_reminder/releases) 页面下载最新版本的 APK 文件，直接安装即可。

### 最低要求

- Android 8.0 (API 26) 或更高版本

## 技术栈

- Kotlin
- Android SDK
- Material Design 3
- ViewBinding
- AlarmManager（系统闹钟 + setAlarmClock）
- Notification（通知提醒 + 快捷操作）
- SharedPreferences（本地持久化）
